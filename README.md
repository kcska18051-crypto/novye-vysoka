# Новые Высока — прототип, версия 11

[Открыть сайт](https://kcska18051-crypto.github.io/novye-vysoka/) · [Контекст и решения](PROJECT-CONTEXT.md) · [Рабочие заметки](dist/notes.html)

Публичный рабочий прототип лендинга проекта «Новые Высока» бренда «Магазин Земли». Будущий сайт планируется на Тильде. Здесь проверяем структуру и пользовательские сценарии.

## Продолжение на другом компьютере

Откройте ссылку сайта для просмотра. Для редактирования скачайте ZIP через Code → Download ZIP либо клонируйте репозиторий. Откройте папку в Codex и начните с PROJECT-CONTEXT.md: там вводные, решения, текущий статус и следующие задачи.

## Локальный просмотр

Откройте dist/index.html в браузере или выполните `node server.cjs`. Адрес сервера: http://127.0.0.1:4173/ . Зависимости и сборка не нужны.

## Файлы и публикация

- dist/ — авторские HTML, CSS и JavaScript; это исходники, а не результат сборки.
- dist/notes.html — материалы, источники и неподтверждённые сведения.
- PROJECT-CONTEXT.md — конспект аналитического обсуждения для продолжения.
- [CHAT-ARCHIVE.md](CHAT-ARCHIVE.md) — текстовый архив этого чата без служебных данных и вложений.
- marketing-funnel-review.md — замечания по воронке; изменения уже включены в версию 06.
- server.cjs — локальный сервер просмотра.

Основная ветка: codex/prototype. GitHub Pages публикуется из корня ветки codex/pages, содержащей только dist. После правок сохраните исходники в основной ветке, а содержимое dist опубликуйте в корне codex/pages отдельным коммитом. GitHub Pages автоматически обновит сайт.

## Статус

Генплан и участки демонстрационные, фотополя ожидают материалы клиента. Формы не отправляют и не сохраняют контакты. Это прототип для обсуждения, а не действующий сайт продаж. Текущие проверки мобильной версии и оставшиеся вопросы перечислены в PROJECT-CONTEXT.md.
