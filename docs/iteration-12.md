# Версия 12 — продукт, УТП и последовательный выбор

По ответам пользователя подтверждены ИЖС, три квартала одного проекта и продажа напрямую собственником. Сценарии покупки равноправны: постоянный дом, дача, дом под аренду. Основное предложение и роли блоков описаны в positioning-and-content.md.

Первое действие — познакомиться с проектом. Затем идут сценарии жизни, окружение и вопросы перед строительством. Генплан начинается с трёх кварталов, отдельные участки открываются после выбора. Общий блок о компании заменён конкретными условиями покупки. Галерея включена в сценарии жизни. Неподтверждённая акция убрана. Сохранены девять FAQ и одна открытая форма, каталог — в диалоге.

Проверено локально в браузере: общий план без участков, переход к кварталу, пустой квартал, фильтр свободных, список, карточка участка, передача выбора в каталог и экскурсию, намерение рассрочки, переключение на видео, закрытие диалога Escape, вкладки галереи. На ширинах 320, 390, 768 и 1440 нет горизонтального переполнения. Внутренние ссылки существуют, ID уникальны, заголовки без конечных точек. Ошибок браузера нет. JavaScript прошёл node --check, изменения — git diff --check.

Ограничения: реальные генпланы, фото, цены и наличие отдельных участков не получены; сохранены явно обозначенные демонстрационные данные. Периодичность 12 платежей неизвестна. Название третьего квартала рабочее. Реальные обращения не отправляются.
