## Что согласовано и сделано

- Единый проект «Новые Высока»: три квартала, участки под ИЖС напрямую от собственника.
- Три сценария покупки без возрастного ограничения: постоянный дом, дача, будущий дом под аренду.
- Главная концепция: «Больше леса, больше жизни». Продажа через образ загородной жизни, сосны, Волгу, воздух и доступность города.
- Первый экран и остальные эмоциональные блоки переписаны. Расшифровка «индивидуальное жилищное строительство (ИЖС)» есть при первом упоминании.
- Цена убрана из строки под героем; показана при выборе квартала.
- Удалён блок «Что важно выяснить до строительства». Не возвращать без отдельного решения пользователя.
- Расположение: сохранена именно исходная схема баннера, предоставленная пользователем. Новые карточки городов удалены. Километраж — ориентиры из схемы, время поездки не добавлено.
- Окружение показано отдельными пунктами: лес, Волга, школа, магазин.
- Порядок схемы и выбора: Николо-Корма → Центральная часть → Дегтярицы. Подписи открытия участков уменьшены.
- Генплан демонстрационный: квартал → участки; номера, площади и статусы вымышлены и отмечены как демо.
- Условия покупки и FAQ конкретные, без метафор. Беспроцентная рассрочка до 12 месяцев без банков; 30% взнос, остаток в 12 равных платежах. Периодичность согласуется в договоре, ежемесячный график не подтверждён.
- По странице центральных участков добавлены связь территорий, 30 м до асфальта и заявленная подготовка земли. Эти свойства не распространены на все кварталы.
- Одна открытая форма внизу: экскурсия / видео; каталог и рассрочка открываются в диалоге. Формы не отправляют и не сохраняют заявки.
- Визуал и логотип пользователь отложил на следующую итерацию. Знак «НВ» временный, не утверждённая айдентика.

## Продолжение на рабочем компьютере

Открыть ветку codex/prototype, скачать ZIP через Code → Download ZIP либо клонировать:
```sh
git clone --branch codex/prototype https://github.com/kcska18051-crypto/novye-vysoka.git
```
Открыть папку в Codex и начать с этого файла и PROJECT-CONTEXT.md.
Локальный просмотр: node server.cjs → http://127.0.0.1:4173/
Не брать ветку codex/pages для редактирования: там только опубликованный сайт.
